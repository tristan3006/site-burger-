# Family'zz — Site vitrine

Site one-page premium pour **Family'zz**, le nouveau restaurant de burgers gourmets de Sucy-en-Brie (21 Place Sainte-Bernadette, 94370 — à côté de l'Auchan).

## Aperçu

- **Hero immersif** : titre animé caractère par caractère, burger SVG dessiné sur mesure dont chaque couche (pain, salade, tomate, fromage, steak) flotte en parallaxe avec la souris et se sépare au scroll.
- **Curseur custom** + boutons magnétiques.
- **Marquee** infini incliné façon grandes marques.
- **Section histoire** avec compteurs animés (4,9★, 66 avis…).
- **Carte interactive** par onglets (Burgers / Sides / Desserts) avec cartes en tilt 3D et effet de brillance.
- **Avis Google** en carrousel draggable.
- **Infos pratiques** : adresse, horaires, itinéraire Google Maps, lien Uber Eats.
- 100 % **HTML/CSS/JS vanilla**, zéro dépendance, responsive, `prefers-reduced-motion` respecté.

## Lancer en local

```bash
# n'importe quel serveur statique, par exemple :
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

## Données réelles vs indicatives

Issues de Google Maps : nom, adresse, note 4,9★ (66 avis), fourchette de prix 10–20 €, services (sur place / à emporter / livraison sans contact).
**Indicatifs** (à ajuster par le restaurant) : les plats et prix de la carte, les horaires, et le texte des avis (reformulés dans l'esprit des retours Google).
